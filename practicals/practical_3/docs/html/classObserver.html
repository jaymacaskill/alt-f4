Detailed Description

Receives notifications from a Subject it is registered with.

Observer is the Observer role in the GoF Observer pattern. Any class that wants to react to a Notice implements update()

virtual void Observer::update ( Notice & notice)
pure virtual

Called by a Subject when a notice is issued Implementation inspects notice.type (and notice.value and notice.message where appropriate) and react according to their rules.

This follows the push model. All information needed to react is contained in notice, so no callback to the Subject is required.
